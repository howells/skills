## Owned Elsewhere

Typeface choice, OpenType features and the type ramp belong to `typecase`. Breakpoints, input modes and safe areas across every view belong to `reflow`; this skill still checks desktop and mobile for the work in hand.

## Baseline Quality

Every branch still inherits Chiaroscuro's entrypoint: authentic content, stable responsive geometry, keyboard and pointer operation, visible focus, inclusive touch targets, accessible semantics, dark-mode integrity, purposeful motion and real browser exercise.
