# Lane I — Marketing & SEO

Run only when recon finds public marketing, pricing, blog, docs or changelog routes; otherwise skip and say so. (Static generation of content routes is B15, fabricated proof is H2 — count each once.)

- **I1. Every public route has `<title>` and description (BLOCKER)** — Hunt: missing or default metadata ("Create Next App"), duplicate title across routes, dynamic routes (`/blog/[slug]`) with static metadata, missing `metadataBase` (breaks relative OG URLs). Wire title templates and `generateMetadata` from existing `<h1>`/excerpts; flag missing copy on the human list.
- **I2. Shared links have an OG preview (BLOCKER for share-driven launches, SHOULD FIX otherwise)** — Hunt: missing `openGraph.images` / `og:image`, `twitter:card` (`summary_large_image`), broken image paths in `public/`, images smaller than 1200×630. Flag missing OG image assets on the human list.
- **I3. Crawlers index real pages only (BLOCKER if `Disallow: /` or staging `noindex` remains, SHOULD FIX otherwise)** — Hunt: missing `robots.txt`/`robots.ts` or `sitemap.xml`/`sitemap.ts`, leftover `Disallow: /` or `noindex`, `/lab` or `/proto` or auth routes listed in sitemap, missing canonicals on multi-URL pages.
- **I4. Real favicon and app icons (SHOULD FIX)** — Hunt: framework default `favicon.ico`, missing `apple-touch-icon`, missing SVG icon, boilerplate manifest `name`/`short_name`. Flag missing artwork on the human list.
- **I5. No hostile scroll theatrics (SHOULD FIX)** — Hunt: `whileInView`/`useInView` leaving content at `opacity: 0` when JS/observer fails or under reduced motion (fix immediately), wheel scroll-hijacking, auto-advancing carousels with no pause control (fix immediately). Ask before removing deliberate scroll animations.
- **I6. Hero intro plays once per session (POLISH)** — Gate intro animations on `sessionStorage` read via a blocking `<head>` script setting `data-intro-seen` on `<html>`, never in `useEffect`.
- **I7. Hero doesn't shift or overflow (SHOULD FIX)** — Preload LCP hero image with dimensions (B1, B3), use `min-h-svh` (C7), `text-wrap: balance` (H5), and check long headline words at 375px.
- **I8. Header submenu links live in the DOM (SHOULD FIX)** — Hunt: `{isOpen && <Submenu />}` hiding nav links from crawlers, screen readers and touch; render in DOM and toggle visibility/disclosure.
- **I9. Auth-aware CTAs stay static-friendly (SHOULD FIX)** — Hunt: hardcoded `/signup` CTA for logged-in users in an app with auth; resolve the CTA client-side so the marketing route stays statically rendered (B15).
- **I10. Conversion path works end to end (BLOCKER)** — Hunt: dead CTA hrefs, pricing page strings disagreeing with billing config, test-mode payment links/keys (`buy.stripe.com/test_`, sandbox URLs), placeholder `mailto:`/social handles, waitlist forms posting nowhere. Put price mismatches and test payment keys above the verdict.
- **I11. Docs and feeds (POLISH)** — Copy buttons with confirmation on code blocks; RSS `<link rel="alternate" type="application/rss+xml">` and `<time datetime>` on blogs/changelogs.
- **I12. Analytics wired once (SHOULD FIX)** — Hunt: duplicate analytics scripts, homepage-only snippets, render-blocking third-party `<script>` without `async`/`defer`, cookie banner shifting layout (E8) or covering mobile CTAs (C15). Leave legal consent decisions on the human list.
- **I13. Device & stranger check (always)** — Put on device list: open production URL in a private window on a phone over cellular; paste URL into Slack, X and iMessage to inspect previews; run mobile Lighthouse on the production build; complete the primary CTA checkout flow in live mode (then refund); view page source to confirm headline and copy render in HTML.
