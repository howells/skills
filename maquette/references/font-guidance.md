# Font guidance

## Selection

Keep the product's existing faces unless the task requires a change. Choose a new
face from the recommendations below, suited to its job and real content. One
family is often enough; add another only when it provides a useful contrast.
Check the actual font files, licence, available weights and rendered results.
For a new pairing, consult real examples on fontsinuse.com or typewolf.com and
test at the sizes the product uses. A specimen is not interface evidence.

Never use Instrument Serif, Playfair Display, Poppins, Montserrat, Roboto or Arial
for a new selection. Only an explicit user instruction overrides this policy.

## Recommended faces

| Job | Recommendations |
| --- | --- |
| UI sans, commercial | Söhne; Founders Grotesk; GT America; Apercu; Akkurat; Maison Neue; Whitney; Untitled Sans |
| UI sans, Google Fonts | Inter; Geist; DM Sans; Hedvig Letters Sans; Outfit; Figtree; Familjen Grotesk; Onest; Libre Franklin; Public Sans; Rethink Sans |
| UI sans, other free self-hosted | General Sans; Satoshi; Switzer |
| Mono | Söhne Mono; Pitch; ABC Repro Mono; Basis Grotesque Mono; Geist Mono; JetBrains Mono; IBM Plex Mono |
| Brand sans | Scto Grotesk; TWK Everett; Brown; Roobert; Sharp Grotesk; SöhneBreit; Space Grotesk; Bricolage Grotesque |
| Serif, commercial | Signifier; Tiempos; Martina Plantijn; GT Sectra; GT Alpina; GT Super; Canela; Lyon; Saol; Sainte Colombe; Mercury; Ivar |
| Serif, Google Fonts | Newsreader; Hedvig Letters Serif; Spectral; Literata; Source Serif 4; Lora; EB Garamond; Fraunces; Cormorant; Crimson Pro; Libre Baskerville |
| Display | Novarese; Knockout; Schnyder; Eksell Display; Editorial New; Bodoni Moda; Libre Caslon Display |

Use the canonical self-hosted InterVariable build when selecting Inter; verify
that required optical-size and cv/ss OpenType features survive delivery.
Use mono for literal code, identifiers or data whose characters need inspection.
Display faces need testing at their intended size and are not default body faces.

## Pairings

Give the display face and body face distinct jobs. Avoid two similar competing
families. These existing recommendations are starting points, not proof that a
pair fits the current product:

| Display / heading | Body / UI |
| --- | --- |

| Novarese | Söhne + Geist Mono |
| Signifier | Inter + Geist Mono |
