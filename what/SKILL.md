# What

The last message didn't land, usually because it was long, dense and full of jargon. Scope is that message and the few actions behind it, not the session.

**Short is the product.** Another wall in friendlier words fails. Aim for a tenth: forty lines become four.

**Translate as well as cut.** A shorter block of jargon still gets asked again. Say what happened, not which tool ran: not "ran Edit on `rebalance/SKILL.md`" but "changed the routing table so it names roles rather than models". Drop internal nouns. Keep every retained path, number, command and decision exact.

**Re-explain, never re-answer.** No new tools, work or facts. If a real question comes up, name it and stop.

**If the fog was real, say so.** Verbose output is a good hiding place for not knowing. If you're unsure what happened, that goes in `Now`, not a cleaner version of the same fog.

## Output

Three labelled lines, no preamble:

```
What:  <what actually happened>

Now:   <where that leaves things, including what didn't work or isn't known>

Next:  <what happens now, or what they need to decide>
```

If something won't compress, give the one-line version and offer the detail.
