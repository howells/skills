# Upstream source and licence

Zoetrope consolidates Emil Kowalski's web animation guidance from [his skill collection](https://emilkowal.ski/skill) and [public repository](https://github.com/emilkowalski/skills). Checked 17 October 2026 at revision `2d228630ba1446365f614a108cb8252f1feda202` (11 October 2026).

The upstream guidance remains the standard. This collection changes packaging and reporting, and adds recipes for preserving identity through expansion and checking layout-projected text. It does not broaden Zoetrope into native animation or film production.

| Upstream material | Where it is retained |
| --- | --- |
| `emil-design-eng`, `animate`, `review-animations`, `improve-animations`, `find-animation-opportunities` | The purpose/frequency gate and build/review/find jobs; `values.md` and `recipes.md` retain easing, durations, physicality, interruption, accessibility, debugging and component patterns |
| `apple-design`, gesture sections of the animation skills | `gestures.md`: contact feedback, direct manipulation, velocity handoff, projection, soft boundaries, spatial consistency, materials, multimodal feedback and reduced motion |
| `animation-performance`, added 11 October 2026 | `performance.md`; its measured, browser-dependent advice updates older categorical acceleration advice in `values.md` |
| `animation-vocabulary` | Consulted for terminology; its standalone reverse-lookup naming workflow is outside Zoetrope's build/review/find jobs |

Static design, typography, native/Expo implementation, library selection and unrelated skills remain outside Zoetrope. Upstream acknowledgement-only opening messages, repo-local plan files and model-specific delegation are adapted to this collection's operating rules. The standalone values and recipes remain bundled so an installation needs no sibling skills.

Emil also added `break-ui` on 2 October 2026. It is interface stress-testing, outside Zoetrope's motion scope.
